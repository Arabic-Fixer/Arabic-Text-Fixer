Three modes

One tool, every use case

Clean Mode
وضع التنظيف

Removes invisible characters, fixes spacing, and converts punctuation. The safest default — works everywhere text is pasted.

Best for: General use, emails, documents
📄
Word Safe Mode
وضع ورد الآمن

Adds RTL HTML formatting that Microsoft Word understands. Paste directly — paragraphs render right-to-left with correct alignment.

Best for: Microsoft Word, LibreOffice

Web Safe Mode
وضع الويب الآمن

Inserts Unicode direction marks (RLM/LRM) at every Arabic–Latin boundary. Fixes display in browsers, Notion, and Google Docs.

Best for: Notion, Google Docs, web apps

How it works

Two ways to use it

طريقتان للاستخدام
1
Select any text

Highlight Arabic text on any webpage — a ChatGPT reply, a news article, a PDF viewer.

2
Right-click → Fix

Choose "Fix Arabic Text" from the context menu. Or click the extension icon to use the popup editor.

3
Paste anywhere

The fixed text is instantly on your clipboard. Paste into Word, Docs, Notion — it renders correctly every time.
